Download the zip and extract the contents of the game into any folder.
Then go to this website: https://sketchfab.com/3d-models/1987-buick-grand-national-regal-gnx-4572494cd9cd432e8da50efb5c7a47c9 and download the free model. Download the GLB file.
Drop the .glb file into the game folder.
Then, open cmd in the folder, or open cmd and cd to the folder.
Type "python -m http.server" to start a localhost server.
Then go to your browser and type "localhost:8000"
Then open Dead Mile.html from the list to make the game work.
